## Authentifizierung

Jede Anfrage trägt den Schlüssel im Header:

```http
X-API-Key: azm_live_ab12cd34ef56_9f4c…
```

**Der Schlüssel bestimmt, wessen Daten die Anfrage sieht.** Es gibt keinen Header, keinen
Query-Parameter und kein Body-Feld, mit dem eine Aufruferin eine Organisation benennen könnte —
der Mandant ergibt sich aus der gespeicherten Schlüsselzeile. Ein Job, der mit einem Schlüssel
erzeugt wurde, ist für jeden anderen Schlüssel unsichtbar; die Abfrage antwortet mit `404`
statt `403`, damit ein Schlüssel nicht dazu taugt, fremde Vorgänge aufzuspüren.

### Schlüsselverwaltung

| Methode | Pfad | Wirkung |
|---|---|---|
| `POST` | `/api/v1/settings/api-keys` | Schlüssel erzeugen. Zweimal aufgerufen ergibt **zwei gültige Schlüssel** — so wird rotiert: erzeugen, ausrollen, widerrufen. |
| `GET` | `/api/v1/settings/api-keys` | Die Schlüssel dieser Praxis, neueste zuerst, ohne Geheimnis. Widerrufene bleiben in der Liste und tragen `revoked_at`. |
| `DELETE` | `/api/v1/settings/api-keys/{key_id}` | Widerrufen. Idempotent. Die Zeile bleibt erhalten — „dieser Schlüssel war von März bis Juli gültig" ist eine Frage, die ein Abrechnungsstreit stellt. |

<Callout type="warn" title="Das Token wird genau einmal angezeigt">
  Gespeichert wird nur sein SHA-256-Hash, niemand kann es Ihnen erneut zeigen. Legen Sie es
  sofort in Ihren Secret Store. Ist es verloren, erzeugen Sie ein neues und widerrufen das alte.
</Callout>

## Prüfung

```bash title="Eine Lieferung synchron prüfen"
curl -X POST https://api.azmoth.com/api/v1/audit/single \
  -H "X-API-Key: $AZMOTH_API_KEY" \
  -F "file=@lieferung.xml"
```

## Was eine Integration früh wissen sollte

- **Eurobeträge sind Dezimal-Strings**, niemals JSON-Zahlen. Wer sie in ein IEEE-Double liest,
  verliert Cent.
- **Regel- und Abdeckungszahlen sind kein Vertragsbestandteil.** Lesen Sie sie zur Laufzeit aus
  `rule_coverage_detail` auf Ihren eigenen Antworten, statt sie fest zu verdrahten.
- **Jobs sind mandantengebunden.** Siehe oben: `404` statt `403`.

## Der verbindliche Vertrag

Fehlercodes, Rate Limits, Stapelverarbeitung und Idempotenz stehen im OpenAPI-Schema, das die
Engine selbst ausliefert — es beschreibt damit immer genau die Fassung, die gerade läuft.
